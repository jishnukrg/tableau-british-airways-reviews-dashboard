# tableau-british-airways-reviews-dashboard

✈️ British Airways Reviews Dashboard (Tableau)

📊 Project Overview

This project analyzes customer reviews for British Airways using Tableau to uncover insights into passenger sentiment, service quality, and overall travel experience. The goal is to transform raw review data into interactive visualizations that help identify trends and improvement areas.

🎯 Objectives
Analyze customer feedback and ratings for British Airways
Identify key factors influencing customer satisfaction
Visualize sentiment trends across different service categories
Build an interactive Tableau dashboard for business insights

📁 Dataset

The dataset contains British Airways customer reviews including:

Overall rating
Review text
Seat comfort
Cabin service
Food & beverages
Entertainment
Recommended (Yes/No)
Traveler type and route details (if available)

Note: Data may be cleaned and preprocessed before visualization in Tableau.

🛠 Tools & Technologies
Tableau Desktop / Tableau Public
Microsoft Excel / CSV (data preprocessing)
Data Cleaning & Preparation Techniques

📈 Key Insights
Overall customer satisfaction trends
Most and least satisfying service areas
Relationship between rating and recommendation likelihood
Patterns in negative vs positive reviews
Service categories impacting passenger experience the most

📊 Dashboard Features
Interactive filters (rating, traveler type, route, etc.)
Sentiment breakdown of reviews
KPI cards (average rating, recommendation rate)
Category wise performance visualization
Trend analysis over time (if applicable)

🧹 Data Cleaning Steps
Removed null and duplicate entries
Standardized rating scales
Converted text reviews into structured format
Handled inconsistent or missing values

🚀 How to View the Dashboard
Download the Tableau workbook file (.twbx) from this repository
Open it using Tableau Desktop or Tableau Public
Explore interactive dashboards and filters

📌 Project Goal

To demonstrate how data visualization can turn customer feedback into actionable business insights that help improve airline service quality.
